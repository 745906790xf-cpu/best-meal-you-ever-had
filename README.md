A tiny Python program that writes one sentence to /output/entry.txt for make.fun's The Best Meal You Ever Had bounty: the best meal the entrant ever had — grandmother's clay-pot rice, eaten at eight years old while rain drummed on the tin roof. The sentence is a fixed string, so every run writes the same bytes.

> My grandmother’s clay-pot rice, crust crackling under my spoon as rain drummed the tin roof and soy and scallion steamed around us — I was eight, and I still measure every good meal against that one.

## Run it

```sh
python3 main.py
```
